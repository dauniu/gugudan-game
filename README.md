# gugudan-game

🎮 구구단 키우기

구구단 공부하고 로블록스 게임 시간 모아보자!

구구단 문제를 풀면서 케이크, 피자, 햄버거, 해바라기, 방울토마토를 단계별로 완성하는 어린이용 구구단 학습 게임입니다.

설치와 회원가입 없이 웹브라우저에서 바로 플레이할 수 있습니다.

🌱 게임 방법

1. 만들고 싶은 항목을 선택합니다.
2. 연습할 구구단을 선택합니다.
3. 총 30문제에 도전합니다.
4. 문제를 맞힐 때마다 그림이 한 단계씩 완성됩니다.
5. 30문제를 끝까지 풀면 정답 개수만큼 코인을 받습니다.
6. 오답이 5개가 되면 게임이 종료되며 해당 판에서는 코인이 지급되지 않습니다.

🪙 코인 규칙

* 정답 1개 = 1코인
* 코인은 30문제를 끝까지 완료했을 때 한 번에 지급됩니다.
* 예: 30문제 중 28문제 정답 → 28코인 적립
* 오답 5회로 게임이 중도 종료되면 → 0코인
* 이전에 모아둔 코인은 그대로 유지됩니다.
* 300코인 = 로블록스 게임시간 +10분 기준으로 사용할 수 있습니다.

코인 보상 방식은 가정에서 원하는 규칙에 맞게 자유롭게 수정해 사용할 수 있습니다.

🎨 만들기 종류

🎂 케이크

빵 → 크림 → 빵 → 딸기 → 초

🍕 피자

도우 → 양파 → 파프리카 → 햄 → 치즈

🍔 햄버거

빵 → 토마토 → 햄 → 상추 → 빵

🌻 해바라기

화분 → 줄기 → 잎 → 잎 → 해바라기

🍅 방울토마토

화분 → 줄기 → 잎 2장 → 토마토 → 토마토

정답을 맞힐 때마다 재료가 하나씩 추가되며, 5단계마다 하나의 작품이 완성됩니다.

* 2~9단 랜덤

⏱️ 게임 규칙

* 총 문제 수: 30문제
* 문제당 제한 시간: 10초
* 최대 오답: 5문제
* 오답 5회 시 해당 게임 즉시 종료
* 게임 완료 후 표시되는 정보
    * 맞힌 문제 수
    * 총 소요 시간
    * 이번 게임 획득 코인
    * 누적 코인

📱 모바일 최적화

아이들이 스마트폰에서도 편하게 사용할 수 있도록 제작했습니다.

* 별도의 스마트폰 키보드를 열지 않는 게임 전용 숫자패드
* 문제와 키우는 그림을 한 화면에서 확인
* 모바일 세로 화면에 맞춘 UI
* 큰 숫자 버튼
* 터치 중심 조작

💾 코인 저장

코인은 브라우저의 localStorage를 이용해 저장됩니다.

같은 기기와 같은 브라우저에서 다시 접속하면 기존 코인이 유지됩니다.

단, 브라우저 데이터를 삭제하거나 다른 기기 또는 다른 브라우저에서 접속하면 기존 코인이 표시되지 않을 수 있습니다.

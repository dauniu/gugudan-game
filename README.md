수학공방
 |아이들이 문제를 풀면서 작품을 완성하고 코인을 모으며 기본 연산을 연습할 수 있도록 만든 웹게임입니다.
 |현재 구구단, 나누기, 덧셈, 뺄셈 공방을 지원합니다.

[게임 구성]
 |구구단 공방
  - 2단부터 9단까지 선택
  - 2~9단 랜덤 모드
  - 총 30문제
  - 문제당 제한시간 10초
  - 오답 5회 시 해당 판 실패

 |나누기 공방
  - 2단부터 9단 기준 나눗셈
  - 답이 자연수로 딱 떨어지는 문제만 출제
  - 2~9단 랜덤 모드
  - 총 30문제
  - 문제당 제한시간 10초
  - 오답 5회 시 해당 판 실패

 |덧셈 공방
  - 합이 10 이하
  - 합이 20 이하
  - 합이 50 이하
  - 합이 100 이하
  - 전체 랜덤(100 이하)
  - 총 30문제
  - 문제당 제한시간 10초
  - 오답 5회 시 해당 판 실패

|뺄셈 공방
 - 10 이하 뺄셈
 - 20 이하 뺄셈
 - 50 이하 뺄셈
 - 100 이하 뺄셈
 - 전체 랜덤(100 이하)
 - 음수가 나오지 않도록 문제 생성
 - 총 30문제
 - 문제당 제한시간 10초
 - 오답 5회 시 해당 판 실패
 
[만들기 시스템]
 |문제를 맞힐 때마다 작품의 재료가 하나씩 추가됩니다.
 |정답 5개마다 작품 1개가 완성되며, 한 판을 성공적으로 끝내면 총 6개의 작품이 기록됩니다.
 |현재 만들 수 있는 작품은 다음과 같습니다.
  - 케이크
  - 피자
  - 햄버거
  - 해바라기
  - 방울토마토
  - 로켓
  - 로봇
  - 자동차
  - 집
 |오답이 5회 누적되어 판이 실패하면 해당 판의 완성품은 기록되지 않습니다.

[코인 시스템]
 |모든 공방은 하나의 공용 코인을 사용합니다.
 |mathWorkshopCoins
 |구구단, 나누기, 덧셈, 뺄셈 공방에서 획득한 코인은 모두 합산됩니다.
 |현재 기준은 다음과 같습니다.
  - 300코인 = 게임시간 10분
  - 코인은 브라우저의 localStorage에 저장됩니다.

[기록보기]
 |records.html에서 지금까지 완성한 작품의 누적 개수를 확인할 수 있습니다.
 |같은 작품은 어느 공방에서 만들었는지와 관계없이 합산해서 표시합니다.
 |예를 들어 구구단 공방에서 로켓 6개, 나누기 공방에서 로켓 12개를 만들었다면 기록보기에는 로켓 18개로 표시됩니다.

[저장 방식]
 |별도의 서버나 데이터베이스를 사용하지 않습니다.
 |브라우저의 localStorage를 사용하기 때문에 같은 기기와 같은 브라우저에서는 페이지를 닫았다가 다시 열어도 코인과 기록이 유지됩니다.
 |다음과 같은 경우에는 저장 데이터가 유지되지 않을 수 있습니다.
 |브라우저 또는 사이트 데이터 삭제
 |다른 기기에서 접속
 |다른 브라우저에서 접속
 |시크릿 또는 프라이빗 모드 사용

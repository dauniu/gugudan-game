# gugudan-game
for kids

🎮 구구단 완성 게임

구구단 문제를 풀면서 음식이나 식물을 하나씩 완성해가는 어린이용 학습 게임입니다.

단순히 문제만 반복해서 푸는 방식이 아니라,
정답을 맞힐 때마다 햄버거, 케이크, 피자, 해바라기, 방울토마토 등이 조금씩 완성되도록 만들어
아이들이 자연스럽게 구구단을 반복 연습할 수 있도록 제작했습니다.

✨ 주요 기능

* 2단부터 9단까지 선택 가능
* 2~9단 랜덤 문제 출제
* 총 30문제를 맞히면 게임 완료
* 문제당 제한 시간 10초
* 틀리거나 시간이 지나면 새로운 문제 출제
* 정답을 맞힐 때마다 만들기 이미지가 한 단계씩 완성
* 게임 성공 시 60코인 지급
* 코인은 브라우저에 누적 저장
* 300코인 달성 시 게임시간 +10분 보상 안내
* 코인 초기화 기능
* 모바일 / PC 브라우저 실행 가능
* 광고 없음
* 별도의 회원가입이나 설치 필요 없음

🍔 만들기 항목

현재 다음 항목을 선택할 수 있습니다.

* 🎂 케이크
* 🍕 피자
* 🍔 햄버거
* 🌻 해바라기 키우기
* 🍅 방울토마토 나무

각 항목은 구구단 문제를 맞힐 때마다 조금씩 완성됩니다.

예를 들어 햄버거는

빵 → 토마토 → 패티 → 상추 → 소스 → 빵

순서로 만들어집니다.

🪙 코인 시스템

게임 한 판에서 30문제를 모두 맞히면 60코인을 받을 수 있습니다.

코인은 같은 기기와 같은 브라우저에서 계속 누적됩니다.

300코인을 모으면

🎮 게임시간 +10분!
엄마에게 결과를 확인시켜줘.

라는 메시지가 표시됩니다.

※ 브라우저의 사이트 데이터를 삭제하거나 다른 브라우저 또는 다른 기기에서 접속하면 저장된 코인이 공유되지 않을 수 있습니다.

🚀 실행 방법

이 프로젝트는 HTML, CSS, JavaScript만으로 만들어진 간단한 웹게임입니다.

index.html 파일을 브라우저에서 열면 바로 실행할 수 있습니다.

GitHub Pages를 이용하면 별도의 서버 없이 무료로 웹에서 배포할 수 있습니다.

🎯 만든 이유

아이에게

“구구단 30문제 풀어.”

라고 하는 것보다

“햄버거 만들어볼래?”

라고 하면 조금 더 재미있게 시작할 수 있지 않을까 하는 생각에서 만들었습니다. 😎

구구단 암기를 공부가 아니라 작은 게임처럼 느끼게 하는 것이 이 프로젝트의 목표입니다.
